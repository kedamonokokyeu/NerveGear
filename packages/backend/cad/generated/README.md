# Microchannel cooling CAD — chip/die-level microfluidics

Generated by `../microchannel_gen.py`. These are complex, importable cooling
geometries that mimic the reference images: **microchannels etched directly into
the die** — the Microsoft die-level microfluidic cooling (biomimetic leaf-vein
networks) and topology-optimized solid/liquid networks.

Die footprint: **20.0 × 32.5 mm**, slab thickness **2.0 mm**, channels etched
**1.2 mm** deep into the top face.

## Three patterns

| Pattern      | Look                                   | Channel area | Solid (128² mask) |
|--------------|----------------------------------------|--------------|-------------------|
| `leafvein`   | organic space-colonization branching   | ~24%         | 0.25              |
| `dendritic`  | dense, mirror-symmetric topology-opt   | ~43%         | 0.18              |
| `htree`      | clean recursive fractal H-tree manifold| ~32%         | 0.22              |

## Files per pattern

- `<name>_die.stl` — the cold-plate/die slab with channels **carved** into the top
  face. Watertight. **This is the part you import.**
- `<name>_fluid.stl` — the coolant volume only (the negative space / channel
  network) — useful for meshing the fluid domain / inlet-outlet BCs.
- `<name>_mask128.npy` — a 128×128 `uint8` solid/liquid map, **1 = solid (fin),
  0 = channel (coolant)**, matching `backend/cad/voxelize.py`'s convention. This
  is the true top-view design field — the direct input for the 2D CFD surrogate.
- `<name>_preview.png` — quick visual (channel field + the 128² mask).

## Validated against the backend import pipeline

Every STL was run through `cad/ingest.py` (`load_mesh` → `normalize`) and
`cad/voxelize.py` (`mesh_to_mask`). All six meshes are **watertight**, normalize
to largest-dim = 1.0 with the correct 0.615 : 1.0 aspect, and compute a finite
volume.

> Note: the die's default `mesh_to_mask` (projection along **z**) returns the full
> rectangular footprint — projecting a slab top-down hides the grooves. To see the
> channels through their voxelizer, project along a **side axis** (`axis=0` or `1`)
> for a fin cross-section, or just use the supplied `_mask128.npy`, which is the
> real top-view solid/liquid field the CFD model wants.

## Import examples

```python
# backend pipeline
from cad.ingest import ingest
from cad.voxelize import mesh_to_mask
mesh, info = ingest("cad_out/leafvein_die.stl")
print(info.watertight, info.extents, info.volume)
mask = mesh_to_mask(mesh)              # or load cad_out/leafvein_mask128.npy directly

# studio (Three.js): drag-drop the .stl, or load via STLLoader
```

## Re-rolling geometry

```bash
python microchannel_gen.py                      # all three, seed 7
python microchannel_gen.py --pattern leafvein --seed 12
```

Tunables live at the top of `microchannel_gen.py` (die size, channel depth,
mesh/field resolution, decimation, smoothing) and in each pattern's
`SpaceColParams` (attractor density, influence/kill radii, Murray's-law width
exponent, `max_nodes` → overall density).
